# offline_pos

## 1.2. Scope of the product
The project aims to establish a robust, fully offline Point of Sale system built with Flutter and SQLite. The application acts as a centralized local hub for retail operations, allowing cashiers to process transactions and store owners to manage inventory without relying on an active internet connection. Designed with eventual cloud synchronization in mind, the system uses string-based UUIDs and a strict relational database structure. It solves common retail challenges, such as the "Milk Problem" (tracking separate expiration dates for identical items) and historical receipt accuracy (locking in item prices at the time of sale).
